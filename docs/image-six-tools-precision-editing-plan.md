# AI Space 图片六大工具精准编辑优化方案

适用范围：`/image/edit` / `/create` 六大图片工具：背景移除、背景替换、文字移除、画质提升、局部重绘、区域涂抹。

目标：把六大工具从“上传后一次性自动处理”升级为“目标可识别、范围可确认、参数可控、结果可验证、局部可修正”的精准编辑系统，尽量做到针对任意一点进行可控修改。

---

## 一、总原则

### 1. 三段式精准执行

所有会改变原图内容的工具，尽量统一为：

```text
识别目标 / 生成处理范围 → 用户确认或微调 → 精确执行 → 前后对比 / 局部修正
```

### 2. 严格区分两类编辑

#### 像素保真型

要求：尺寸不变、构图不变、主体不被重绘。

适用：

- 背景移除
- 背景替换
- 文字移除
- 保真画质提升

原则：优先使用本地分割、蒙版、合成、传统图像处理，不把整图交给生成式模型重绘。

#### 生成修改型

允许模型生成新内容，但必须限制在选区内。

适用：

- 局部重绘
- 区域涂抹
- AI 超分 / AI 细节增强

原则：蒙版外像素尽量保持不变，蒙版尺寸与源图尺寸严格对齐。

### 3. 所有工具统一输出校验

每个任务完成后必须记录或验证：

- 输出视觉尺寸是否等于输入视觉尺寸
- 是否错误重绘未选区域
- 处理区域是否为空或过大
- 是否触发 provider fallback
- 失败原因要区分阶段：源图读取、上传、蒙版导出、任务创建、异步处理、结果保存

## 二、六大工具优化细项

## 1. 背景移除

### 目标

从“能抠图”升级为“边缘可精修”。

### 优化项

1. 前端暴露模式：
   - 标准抠图：普通人物/物体
   - 发丝/毛发精修：头发、猫狗、羽毛
   - 商品硬边：瓶子、盒子、电子产品
   - 去白边/去黑边：边缘去杂色
2. 结果预览背景：
   - 透明棋盘格
   - 白底
   - 黑底
   - 自定义纯色
3. 增加修边笔刷：
   - 恢复主体
   - 擦除残边
   - 边缘羽化
   - 去杂色
4. 后端要求：
   - 使用 EXIF 视觉方向作为基准
   - 输出 PNG/RGBA
   - 输出尺寸等于输入视觉尺寸
   - 不使用生成式全图重绘

---

## 2. 背景替换

### 目标

只替换背景，主体像素尽量原样保留。

### 推荐链路

```text
原图 → 主体蒙版 → 生成/选择背景层 → 原主体像素合成回去 → 光影/边缘融合
```

### 优化项

1. 前端模式：
   - 纯色背景
   - 电商棚拍
   - 影棚渐变
   - 真实场景
   - 风格化背景
2. 增加背景构图参数：
   - 光线方向
   - 景深强度
   - 色温
   - 主体接触阴影
   - 背景虚化
3. 增加主体保护开关：
   - 严格保护主体像素
   - 允许轻微边缘融合
4. 后端要求：
   - 生成背景层，不重绘主体
   - alpha composite 回原主体
   - 输出尺寸等于输入视觉尺寸

---

## 3. 文字移除

### 目标

从“自动擦字”升级为“文字区域可确认”。

### 推荐流程

```text
上传图片 → 自动检测文字区域 → 红色蒙版预览 → 用户确认/补涂/删除 → 执行去字
```

### 优化项

1. 增加检测强度：
   - 保守：避免误删图标/主体
   - 标准：默认
   - 强力：水印、黑板、海报密集文字
2. 显示红色文字检测蒙版。
3. 允许用户手动补涂漏检文字。
4. 允许用户擦除误检区域。
5. 保留图标/Logo/主体内容，不把图标与文字标签合并误删。
6. 增加二次修复：
   - 轻度修补
   - 纹理增强
   - 边缘融合

---

## 4. 画质提升

### 目标

明确区分“保真增强”和“AI 重绘增强”。

### 模式

1. 保真增强：
   - 尺寸不变
   - 构图不变
   - 不重绘脸和主体
   - 只做降噪、锐化、对比度、轻微色彩修复
2. AI 超分：
   - 可 2x/4x 放大
   - 可生成细节
   - 需要提示用户可能改变细节
3. 局部增强：
   - 只增强脸
   - 只增强文字
   - 只增强商品
   - 只增强模糊区域

### 参数

- 降噪强度
- 锐化强度
- 细节增强
- 色彩修复
- 面部保护

---

## 5. 局部重绘

### 目标

选区准、替换准、未选区域不变。

### 推荐流程

```text
涂抹目标 → 智能识别对象轮廓 → 显示对象名与蒙版 → 用户确认 → 输入替换内容 → 执行重绘
```

### 前端必须显示

- 已识别对象名，例如：电脑、人物上衣、桌面杯子
- 蒙版覆盖率
- 选区边界
- 是否需要扩张/收缩

### 模式

- 替换成新物体
- 修改当前物体
- 添加新元素
- 修复破损区域
- 改颜色/材质

### 蒙版控制

- 扩大一点
- 扩大很多
- 收缩一点
- 羽化边缘
- 清除重画

### 后端要求

- mask 与 source 尺寸完全一致
- 蒙版外像素尽量不变
- 对 OpenAI/Edit 类模型提交二值 alpha mask
- 识别用压缩图时，最终编辑必须 remap 回原图尺寸

---

## 6. 区域涂抹

### 目标

删除选中物体并自然补全背景，不等同于替换物体。

### 推荐流程

```text
涂抹要删除的物体 → 智能识别完整物体/阴影 → 用户确认 → 删除并修复背景
```

### 模式

- 普通删除
- 包含阴影
- 强力清除

### 可选项

- 只删除物体
- 删除物体和阴影
- 删除物体、阴影、反光

### 背景类型识别

后续可增加：

- 平面背景
- 纹理背景
- 线性纹理，例如地砖/木纹
- 透视平面，例如道路/墙面
- 自然背景，例如草地/水面

---

## 三、共享能力层

### 1. 统一选区系统

所有局部型工具共享：

- 画笔
- 橡皮
- 智能识别
- 扩张/收缩
- 羽化
- 清除
- 反选
- 处理区域预览

### 2. 处理范围预览

执行前显示：

```text
红色：将被修改
绿色：将被保护
蓝色：边缘融合区域
```

用户确认后再创建正式任务。

### 3. 局部回退

结果图上允许：

- 恢复原图
- 应用结果
- 局部重新生成

### 4. 失败反馈入口

每个结果提供结构化反馈：

- 选区不准
- 改错地方
- 没有改干净
- 主体变形
- 尺寸变化
- 画质变差
- 文字残留
- 背景不自然

## 四、第一阶段实施任务

优先做低风险、收益高的精准控制。

1. 前端六大工具增加可见模式选择：
   - 背景移除：标准 / 发丝毛发 / 商品硬边 / 去边
   - 背景替换：纯色 / 电商 / 影棚 / 真实 / 风格化
   - 文字移除：保守 / 标准 / 强力 / 水印
   - 画质提升：保真 / AI 超分
   - 局部重绘：替换 / 修改 / 添加 / 修复
   - 区域涂抹：普通删除 / 包含阴影 / 强力清除
2. 前端提交时透传 `sub_mode` 和 `intent`。
3. 局部重绘和区域涂抹在未完成识别时禁止最终执行。
4. 局部工具显示识别对象名、覆盖率和选区状态。
5. 为文字移除预留“检测蒙版确认”状态。
6. 后端记录 route 的 edit_mode/sub_mode/intent，保证默认兼容旧客户端。

## 五、第二阶段实施任务

1. 文字移除增加检测蒙版接口和前端确认步骤。
2. 背景移除增加边缘修复笔刷。
3. 背景替换走主体原像素合成链路。
4. 画质提升增加保真参数滑杆。
5. 所有工具加入输出尺寸校验和失败原因分层。

## 六、验收标准

### 功能验收

- 六个工具都能选择具体处理模式。
- 默认模式保持旧行为兼容。
- 局部重绘/区域涂抹必须识别选区后才能执行。
- 输出结果能在历史中正常显示和下载。

### 技术验收

- `frontend npm run build` 通过。
- `backend go test ./internal/services ./internal/api` 通过。
- 关键图片脚本至少保留输出尺寸一致。

### 体验验收

- 用户能在执行前知道系统将处理哪里。
- 用户能控制强度/模式，而不是只能靠一句 prompt。
- 出错时能知道失败阶段，不再只有泛化“生成失败”。
