# AI Pool — AI 聚合平台产品说明书

> 版本：v2.1 | 架构：Go/Gin + Next.js | 部署：单二进制 + 静态导出

---

## 一、产品简介

**AI Pool** 是一个企业级多模型 AI 聚合平台，为企业和开发者提供**开箱即用的白标 AI 平台解决方案**。它通过单一接入点统一管理 GPT（OpenAI）、Claude（Anthropic）、DeepSeek、Moonshot/Kimi 等主流大模型，并在此基础上构建了完整的会话管理、技能系统、图片工作台、文件检索（RAG）、积分计费和对话分享等上层能力。

**一句话定义：** 它是一个可以贴上你的 Logo、配置你的模型、定制你的角色的 AI 平台——不需要一行后端代码。

### 核心架构

- **后端：** Go 1.22 单一二进制（约 20MB），SQLite 嵌入式数据库，无外部依赖
- **前端：** Next.js 静态导出（Static Export），纯静态 HTML/JS 文件
- **部署：** 一个二进制文件 + 一个静态目录 = 完整的 AI 平台服务
- **认证：** JWT + bcrypt，支持登录/注册/匿名访客

## 二、产品核心优势

### 优势一：深度可定制的产品界面（品牌白标能力）

AI Pool 面向 B 端客户最核心的卖点——**从界面到能力，每一层 UI 都可以定制为客户品牌风格**。

| 可定制层级 | 实现方式 | 修改成本 |
|-----------|---------|---------|
| **品牌 Logo 与名称** | 侧边栏 `"AI Space"` → 替换为任意品牌名 | 1 行代码 |
| **完整配色系统** | `tailwind.config.ts` 定义 primary/surface/border/text 全套 CSS 变量 | 5 分钟换肤 |
| **深色/浅色双主题** | `ThemeProvider` + `data-theme` CSS 变量，双主题同时适配品牌 | 增减变量即可 |
| **侧边栏布局** | 260px ↔ 52px 折叠切换，功能项可增删 | 模块化组件直接编辑 |
| **页面路由** | 聊天/技能市场/图片编辑/定价/模板/分享/工作区 | 选择性暴露或隐藏 |
| **技能图标与配色** | 每个角色可配独立图标+颜色映射 | 编程映射配置 |
| **定价页面** | 套餐、功能列表、按钮文案纯静态配置 | 配置文件级 |
| **着陆页 SEO** | Metadata（标题/描述/关键词）完全可控 | `layout.tsx` 编辑 |
| **全局字体与动画** | TailwindCSS 自定义动画系统 | Tailwind 层扩展 |

> **商业价值：** 教育机构、企业内部平台、咨询公司等需要私有部署的客户，不需要重新开发前端，只需替换 CSS 变量和 Logo，就能拥有完全属于自己品牌的企业 AI 平台。

### 优势二：稳定可靠的 AI 技术底座

#### 多模型统一接入
- 单一 API `/api/chat/stream` 管理 GPT、Claude、DeepSeek、Kimi 等 4+ 模型家族
- 每个模型家族独立配置 Base URL，支持代理/中转部署
- 多模态图片输入：原生支持 GPT、Claude、Kimi；同时通过 RAG→Vision 机制为所有纯文本模型提供图片理解能力

#### SSE 实时流式响应
- 完整 SSE 流式传输，支持 context 窗口管理、token 追踪、自动 retry
- 前端增量渲染，用户体验流畅

#### 文件智能解析与 RAG 检索
- 支持 PDF、Office 文档（Word/PPT/Excel）、图片
- 自动解析 → 文本分块 → Embedding → 向量检索
- 文件 Chunk 结构化（段落/表格/代码/图片引用）
- 多 Embedding Provider 共存，全自研检索管线

#### 图片生成与编辑工作台
- **生成：** gpt-image-2 引擎，支持 1:1~21:9 纵横比、1K~4K 分辨率、4 级质量
- **编辑：** 背景移除、背景替换、文字移除、画质提升——这些通常在独立 SaaS（Remove.bg、Clipdrop）上的功能，聚合在一个聊天平台中
- 参考图上传 → 引用编辑，结果自动保存可分享

#### 技能插件动态注入
- 运行时增删 AI 角色（无需重启），每个角色有独立 manifest（名称/描述/图标/系统提示等）
- 支持 `co_skills` 组合形成复合能力
- 对标 ChatGPT 的 GPTs 但完全开放、可自定义

#### 三级积分计费系统
- 按基础/高级/精英三级积分区分模型级别，Token 级别自动扣费
- 支持 consume/debit/refund 完整生命周期
- 免费用户每日自动重置配额

#### 安全与用户体系
- JWT 认证 + bcrypt 密码哈希
- 完整登录/注册/匿名访客三态用户体系
- CORS 配置支持跨域部署

## 三、稀缺性能力（差异化优势 + 规划方向）

### ✅ 当前已具备的稀缺能力

| 能力 | 稀缺性说明 | 竞品对标 |
|------|-----------|---------|
| **技能插件动态注入** | 运行时增删 AI 角色（无需重启），每个角色即一个可编程 agent manifest | Poe 无法运行时热加载；OpenRouter 没有；ChatGPT GPTs 不开源 |
| **图片编辑工作台** | 背景移除/替换、文字移除、画质提升——聚合到 AI 聊天平台中极罕见 | ChatGPT 仅生成无编辑；Poe 无；OpenRouter 无 |
| **三级积分 + Token 计费** | 按模型级别差异化定价，支持 refund，比固定订阅灵活 | ChatGPT/Claude 固定订阅；Poe 点数制；OpenRouter 固定 Token 价 |
| **RAG + Vision 双路径** | 文件 RAG→Vision→文本注入（纯文本模型也能看图片） + 原生多模态并行 | Poe 不支持文件 RAG；ChatGPT 文件仅 GPT-4 可用 |
| **统一流式 API 网关** | 单一前端 API，后端按模型分发，自带会话管理和中间件 | OpenRouter 仅路由，无会话无中间件 |
| **对话分享** | URL Slug 分享，选择性展示消息，适合展示给客户/团队 | ChatGPT 有分享；Poe 无；OpenRouter 无 |
| **单二进制私有部署** | Go 20MB 二进制 + 静态前端目录 = 完整平台，低资源消耗 | ChatGPT/Claude 不可部署；OpenRouter 不可部署 |
| **Workspace 空间隔离** | 对话/文件/用户按工作区隔离，侧边栏一键切换，独立 CRUD 管理 | ChatGPT Team 版有；Poe 无；OpenRouter 无 |

### 🚀 规划中的稀缺能力（按优先级）

#### P0 — 近期

1. **引用原文可视化交互**
   - 回答中的数字引用 `[1]` `[2]` 可点击，弹窗展示对应文件原文段落的高亮
   - **RAG 基础设施已完成**（分块、Embedding、检索、引用编号），只差前端交互
   - 对标 Sider Wisebase / NotebookLM 的点击引用跳转原文

2. **嵌入模式 Widget**
   - 客户一行 `<script>` 在自己的网站嵌入 AI Pool 聊天
   - 配置项：主题色、位置、触发方式
   - **价值：** API 集成门槛太高？直接嵌入，非技术客户也能对接

3. **URL 链接导入文件**
   - 粘贴网页链接 → 自动抓取内容并作为文件源
   - 对标 Notion / Sider 的"粘贴链接导入"功能

4. **用量分析看板**
   - 用户级别的 API 调用统计：日活、Token 消耗趋势、模型使用分布、错误率
   - **价值：** ChatGPT 不提供；OpenRouter 基础版

5. **多语言界面**
   - 当前中英文硬编码 → i18n 动态切换
   - **价值：** 服务出海/外企客户

#### P1 — 中期

6. **笔记系统（高亮 → 笔记 → 数据源）**
   - 阅读文件时高亮重要内容保存为笔记
   - 笔记可作为聊天数据源注入
   - 对标 Sider Wisebase 的笔记面板
   - **工作量评估：** 后端新增 Note 模型（CRUD）+ 前端笔记面板组件 ≈ 2-3 天

7. **Deep Research 深度文档分析**
   - 用户点击"全面分析" → AI 一次性分析所有文件 → 输出结构化报告
   - 对标 Sider 的"深入研究"/Notion AI 的文档分析

8. **企业级多租户（Org + 团队隔离）**
   - 一个部署服务多客户，独立用户/技能/定价
   - Workspace 功能已上线，下一步：Org 组织层 + 成员邀请 + 权限角色

9. **API Key 自服务门户**
   - 用户生成自己的 API Key，通过 OpenAI 兼容格式调用 AI Pool
   - **价值：** 从聊天平台 → AI API 市场，商业模式转型关键节点

10. **Agent 工具箱（Function Calling UI 化）**
    - 聊天中搜索网页、计算、查数据库等工具
    - 后端已有 Tavily/Brave 配置，前端暴露 Tool Choice 界面即可

#### P2 — 长期

11. **模型成本优化层**
    - 简单问题 → 便宜模型，复杂问题 → 旗舰模型，自动路由
    - 重复问题缓存，失败时自动切换替代模型

12. **自定义 Agent 构建器**
    - 拖拽式 Agent 工作流：输入 → 模型调用 → 工具调用 → 输出
    - Agent 可共享/出售（Agent Store）
    - 对标 Coze / Poe Bot Builder，但私有部署

13. **PDF 翻译器**
    - 文件列表中选择 PDF → 选择目标语言 → AI 翻译 → 保留原格式
    - 可通过现有技能系统快速实现，无需独立开发

## 六、总结

**AI Pool 的核心竞争力不是模型数量（比不过 OpenRouter），也不是品牌知名度（比不过 ChatGPT），而是：**

1. **「开箱即用的白标 AI 平台」** — 从界面到能力，从计费到分享，一个 20MB 二进制文件搞定
2. **「聚合 + 增强」** — 不仅是路由转发，还拥有 RAG、图片编辑、技能插件、三级计费等**其他平台不具备的上层能力**
3. **「单机可部署」** — Go 单二进制 + 静态前端，低资源消耗，适合中小企业和自部署场景
4. **「Workspace 空间隔离已上线」** — 对话、文件按工作区隔离，侧边栏一键切换

### 与 Sider Wisebase 对标的差距与追赶计划

**Sider 的核心优势在浏览器扩展生态**（保存网页、高亮内容到 Wisebase），这是纯 Web 应用无法竞争的。但在纯产品功能层面，差距并不大——RAG、文件上传、Workspace 管理这些核心骨架 AI Pool 都已具备。

**最短路径补齐 RAG 体验短板（1-2 周）：**

| 功能 | 优先级 | 工作量 | 差距 |
|------|--------|--------|------|
| 引用原文高亮可视化 | **P0 本周** | 2 天前端 | RAG 基础设施完成，只差交互 |
| URL 链接导入文件 | **P0 本周** | 1 天 | 新增后端 `FetchURL` 解析 + UI 入口 |
| 笔记系统 | **P1 两周** | 3 天 | 全新增，后端模型 + 前端面板 |

完成这三项后，AI Pool 在纯产品层面的 Wisebase 对标基本追平 + 额外拥有图片编辑、技能热加载、积分计费等 Sider 不具备的能力。

> **下一步聚焦方向：** RAG 体验补齐 → 嵌入 Widget → 多租户团队 → API Key 自服务门户，四步完成后 AI Pool 将从「AI 聊天平台」进化为「AI 基础设施平台」。
