# AI 聚合平台项目策划案

## 一、项目定位

**名称**：待定（建议简洁易记，如 ChatHub / AIHub / 智聚合）
**Slogan**：一个入口，所有顶尖 AI
**目标用户**：国内个人用户、学生、职场人士、中小企业
**核心痛点**：
- 国内用户无法直接访问 GPT、Claude 等海外 AI
- 多个 AI 平台来回切换，体验割裂
- 海外 AI 付费门槛高（需要外币信用卡、容易被封号）
- 中文场景下各模型表现参差不齐，需要一个"智能路由"自动选择最佳模型

---

## 二、竞品分析（ToxAI 拆解）

| 维度 | ToxAI 现状 | 我们的机会点 |
|------|-----------|------------|
| **技术栈** | Next.js + React，现代化前端 | 可借鉴，但我们可以加入更多本土优化 |
| **模型覆盖** | Claude、GPT、Gemini 聊天 + gpt-image-2 画图 + PPT | 可以扩展更多国产模型（DeepSeek、Kimi、通义千问、文心一言） |
| **功能模块** | 聊天 / 画图 / PPT / 联网搜索 | 可以增加：文档解析、语音对话、代码解释器、Agent 市场 |
| **UI 设计** | 左侧导航栏 + 中间会话列表 + 右侧聊天区，简洁现代 | 参考其布局，但增加更多自定义皮肤和主题 |
| **用户体系** | 必须登录才能保存对话历史 | 可以提供游客模式（限量体验），降低使用门槛 |
| **商业模式** | 推测为会员订阅制（按量/包月） | 可以采用"免费额度 + 会员订阅 + API 接口"三级模式 |

## 三、核心功能模块

### 3.1 多模型聊天（MVP 核心）
- **一键切换模型**：在聊天界面顶部添加模型选择器，支持 GPT-4o / Claude 3.5 Sonnet / Gemini 2.0 / DeepSeek-V3 / Kimi k1.5 等
- **模型对比模式**：同一个问题同时发给 2-3 个模型，并排展示回答，方便用户对比
- **智能路由**：用户输入问题后，系统自动判断哪个模型最适合回答（比如代码问题走 Claude，创意写作走 GPT，长文档走 Kimi）
- **联网搜索**：接入搜索引擎（Serper / Bing API），让模型可以获取实时信息
- **文件上传**：支持 PDF / Word / Excel / 图片上传，让模型做文档解析、OCR、数据分析

### 3.2 AI 画图（V1.0）
- 集成 DALL·E 3、Midjourney API、Stable Diffusion、gpt-image-2
- 提供中文提示词自动优化（将用户的简单描述翻译成高质量英文 prompt）
- 画廊展示社区优秀作品

### 3.3 文档/PPT/代码助手（V1.5）
- **PPT 生成**：输入主题，AI 自动生成大纲 + 内容 + 排版，可导出 .pptx
- **文档处理**：上传 PDF/Word，AI 总结、翻译、提取关键信息、问答
- **代码助手**：支持代码补全、解释、重构、Bug 修复，接入 GitHub Copilot 风格

### 3.4 AI Agent 市场（V2.0）
- 预设各种场景 Agent：小红书文案助手、论文降重助手、简历优化师、法律咨询助手等
- 支持用户自定义 Prompt 并分享到市场
- 每个 Agent 可以绑定特定模型 + 特定参数

### 3.5 语音交互（V2.0）
- 语音输入（语音识别）
- 语音播报（TTS，让 AI 用声音回复）
- 模拟语音对话体验

## 五、商业模式

### 5.1 免费用户
- 每日 20 次基础模型对话额度
- 无法使用高级模型（GPT-4o / Claude 3.5）
- 无法保存历史记录（或仅保存最近 3 条）

### 5.2 会员订阅（主力收入）
| 档位 | 价格（参考） | 权益 |
|------|------------|------|
| 基础版 | ¥29/月 | 每日 100 次，可用 GPT-4o-mini / DeepSeek |
| 专业版 | ¥69/月 | 每日 500 次，可用 GPT-4o / Claude 3.5 / Gemini，支持文件上传 |
| 高级版 | ¥169/月 | 无限次（合理范围内），全模型 + 画图 + PPT + 优先响应 |

### 5.3 API 接口（B 端收入）
- 向开发者提供统一 API，按 Token 计费
- 价格比官方低 10-20%，但比我们自己采购成本高 30-50%（赚差价）

### 5.4 企业定制
- 私有化部署
- 企业内部知识库 + AI 问答
- 定制 Agent

## 六、差异化竞争策略

1. **比 ToxAI 更多模型**：不仅做海外模型，还要接入国内最好的模型（DeepSeek、Kimi），让用户在同一个地方比较海内外 AI 的差异
2. **中文场景优化**：
   - 预设大量中文 Prompt 模板（小红书文案、抖音脚本、公文写作、论文降重）
   - 针对中文长文本优化（Kimi 的 200 万字上下文是巨大卖点）
3. **本地化体验**：
   - 微信支付 / 支付宝订阅
   - 国内服务器部署，访问速度快
   - 客服用中文
4. **价格优势**：通过批量采购 API + 国产模型补充，把成本压下来，会员价比用户自己买 ChatGPT Plus + Claude Pro 便宜

## 八、风险与应对

| 风险 | 应对策略 |
|------|---------|
| 海外 API 被封/限流 | 多账号池轮换 + 国产模型作为兜底 |
| 政策合规 | 接入内容安全审核（阿里云/百度内容审核 API），过滤敏感词 |
| 成本失控 | 设置用户级限流 + 模型降级策略（高峰期用便宜模型） |
| 同质化竞争 | 聚焦"中文场景 + 国内模型 + 价格优势"，不做大而全 |

---

## 九、总结

这个项目市场空间很大——国内想用上 GPT/Claude 但没有条件的人太多了。ToxAI 已经验证了模式可行，但功能还可以做得更丰富、更本土化。

**核心公式**：海外顶尖模型 + 国产优质模型 + 中文场景优化 + 低价会员 = 一个有竞争力的 AI 聚合平台。
