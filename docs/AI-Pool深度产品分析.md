# AI Pool 深度产品分析

> 版本：v3.0 | 架构：Go/Gin + Next.js 14 | 部署：20MB 单二进制 + 静态前端
> 数据库：嵌入式 SQLite (零依赖) | 前端：Next.js 静态导出 (无运行时)
> 端口：后端 9091 + 前端 9090 (Cloudflare Tunnel 对外暴露)

---

## 一、产品简介

**AI Pool 是一个面向企业/团队的私有化 AI 聚合平台——客户部署一次，就拥有一个完整的、可贴自己 Logo 的 ChatGPT 替代品。**

### 一句话定位
> **能贴你 Logo、走你模型、用你角色的企业级 AI 工作台，一个 20MB 的二进制文件搞定一切。**

### 它在做什么？
目前市场上用户获取 AI 能力的路径都是**被平台锁定**的：
- 用 ChatGPT → 谷歌 Logo、OpenAI 计费、不能定制
- 用 Claude → Anthropic 的生态、不能私有部署
- 用 Poe → Quora 的品牌、不能白标

**AI Pool 要解决的问题很简单：** 企业想要一个 AI 平台，但它不想让员工看到别人的 Logo，不想把数据交给第三方的服务器，不想每个月按人头付固定订阅费。

## 二、核心优势（为什么客户选择 AI Pool 而非竞品）

### 优势维度一：定制化的产品界面——「把 AI 平台变成你的品牌」

**这是 AI Pool 对 B 端客户最大的吸引力。** 不是所有企业都想让员工看到一个带别人 Logo 的 AI 工具。

#### 1. 品牌白标（White-Label）——全栈可品牌化

| 可定制层级 | 实现方式 | 修改成本 | 效果 |
|-----------|---------|---------|------|
| **Logo + 品牌名** | 侧边栏标题、"AI Space" → 你的品牌名 | 1 行代码 | 平台首页看起来就像你自研的 |
| **完整配色系统** | TailwindCSS CSS 变量，primary/surface/border/text 全套主题变量 | 5 分钟换肤 | 深色/浅色双主题同时适配品牌 |
| **侧边栏菜单** | 260px ↔ 52px 折叠，功能项可增删 | 模块化组件直接编辑 | 只展示你想给用户看的功能 |
| **页面路由** | 聊天/技能/图片/PPT/定价/模板/工作区 | 选择性暴露或隐藏 | 「看什么」完全由你控制 |
| **技能角色图标** | 每个角色对应独立图标+颜色映射 | 编程映射配置 | 丰富有趣的角色呈现 |
| **定价页面** | 套餐定价、功能列表、按钮文案 | 纯静态配置 | 走你的付费模式 |
| **着陆页 SEO** | Metadata（标题/描述/关键词）完全可控 | `layout.tsx` 配置 | 搜索引擎展示你的品牌 |
| **全局字体/动画** | TailwindCSS 自定义动画系统 | Tailwind 层扩展 | 风格统一 |

**商业价值场景举例：**
- **教育机构** → 贴上学校 Logo，师生使用「XX 大学 AI 助手」
- **企业内部** → 公司品牌色+Logo，员工使用「XX 公司 AI 工作台」
- **咨询公司** → 为客户搭建私有 AI 平台，展示自身技术能力
- **SaaS 厂商** → 集成到自己的产品中作为 AI 模块

#### 2. 极低的白标成本

竞争对手要实现同等白标程度：
- ChatGPT Team/Enterprise → ❌ 不可定制界面
- Poe for Business → ❌ 不可定制界面
- OpenRouter → ❌ 无前端
- 自研 → 至少 3-6 月开发周期 + 前端工程师人力成本

**AI Pool：替换 3 个 CSS 变量 + 1 个文字标题，5 分钟搞定。**

#### 3. 可选择性暴露能力

不想给用户看到「AI PPT」？去掉侧边栏路由就行。不想展示「图片编辑」？移除菜单项。整个功能矩阵可以像搭积木一样选择展示。

### 优势维度二：稳定可靠的技术底座——「不是套壳转发，是有深度的 AI 基础设施」

#### 1. 多模型统一引擎（不是简单的 API 网关）

| 特性 | AI Pool | OpenRouter | ChatGPT |
|------|---------|-----------|---------|
| 模型数量 | 4+ 家族 (GPT/Claude/DeepSeek/Kimi) | 200+ | 仅 OpenAI |
| **统一流式接口** | ✅ 全部走 `/api/chat/stream` | ⚠️ 各自 API 格式不同 | ✅ 自己生态 |
| **会话管理** | ✅ 完整 CRUD + 自动保存 | ❌ 无会话 | ✅ |
| **中间件支持** | ✅ IP 限流/速率控制/JWT/CORS | ❌ 无 | ❌ 无 |
| **多模态兼容** | ✅ RAG→Vision 双路径（文本模型也能看图片） | ❌ 纯文本路由 | ✅ 仅 GPT-4 可用 |
| **错误重试** | ✅ 自动 retry | ❌ | ❌ |
| **Token 追踪** | ✅ SSE 实时推送 Token 消耗 | ❌ | ✅ |

#### 2. 文件 RAG 管线——全自研、无外部依赖

```
用户上传
   ↓
FileParser（PDF/Office/图片 → 纯文本 + 结构化分块）
   ↓
File Chunker（段落 / 代码块 / 表格 / 图片引用 分级分块）
   ↓
Embedding Provider（可配置 OpenAI / 本地 / 其他 Provider）
   ↓
Retrieval Service（向量检索 + 关键词降级）
   ↓
Context Builder（智能上下文窗口拼装）
   ↓
AI Response（带引用编号 `[1]` `[2]` 的回答）
```

**稀缺性：** 其他聚合平台（Poe、OpenRouter）不提供文件 RAG。ChatGPT 的文件功能限于 GPT-4。**AI Pool 把所有模型都变成了「文件理解型模型」**——通过 RAG→Vision 双路径，即使纯文本的 DeepSeek 也能分析图片内容。

#### 3. 图片编辑工作台——聚合多步编辑工具

| 功能 | AI Pool | ChatGPT | Sider | Midjourney |
|------|---------|---------|-------|-----------|
| 图片生成 | ✅ gpt-image-2 | ✅ DALL-E | ❌ | ✅ |
| **背景移除** | ✅ 原生支持 | ❌ | ❌ | ❌ |
| **背景替换** | ✅ 原生 + 参考图 | ❌ | ❌ | ❌ |
| **文字移除** | ✅ AI 擦除 | ❌ | ❌ | ❌ |
| **画质提升** | ✅ 高清化 | ❌ | ❌ | ⚠️ |
| **工作台集成** | ✅ 同一界面内完成 | ❌ | ❌ | ❌ |

**这意味着：** 用户不需要打开 Remove.bg 移除背景 → 打开 Clipdrop 替换 → 再回到 AI 平台提问。全部在一个界面中完成。

#### 4. 技能插件系统——运行时热加载，对标 GPTs 但更灵活

- **运行时热加载：** 新增/修改角色，**无需重启服务**
- **每个角色 = 一个独立 manifest：** 名称、描述、图标、配色、系统提示、示例对话
- **co_skills 组合：** 多个技能叠加形成复合能力
- **对标：** ChatGPT GPTs（不开源不可定制）→ AI Pool（完全开放、可编程）

**当前内置技能（9 个）：**
CEO战略顾问、代码审查专家、创意写作、数据分析师、邮件起草、会议纪要、提示词工程师、论文助手、翻译

#### 5. 三级积分 + Token 计费——比固定订阅灵活 10 倍

| 特性 | AI Pool | ChatGPT/Claude | Poe |
|------|---------|---------------|-----|
| 计费粒度 | Token 级 | 固定月费 | 点数制 |
| 模型分级 | 基础/高级/精英三级 | 单一定价 | 不同模型不同点数 |
| 退款支持 | ✅ consume/debit/refund 完整生命周期 | ❌ | ❌ |
| 免费配额 | ✅ 每日自动重置 | ❌ | ✅ 有限 |
| 计费透明 | ✅ 逐 Token 审计 | ❌ 黑盒 | ⚠️ |

#### 6. 单二进制私有部署——15 秒完成部署

```
# 部署流程
1. 下载 aipool 二进制 (20MB)
2. 上传 dist/ 前端目录
3. 配置 .env (模型 API Key)
4. ./aipool + node server.js → 启动完成
```

**资源消耗：** 1 核 CPU + 256MB 内存即可运行。对比 ChatGPT/Claude 不可部署、Poe 不可部署、OpenRouter 不可部署。

#### 7. Workspace 空间隔离——已上线的多空间管理

- 每个用户可创建多个 Workspace
- 对话、文件、图片按 Workspace 隔离
- 侧边栏一键切换 + 独立管理页面
- **商业价值：** 一个平台实例管理多个项目/客户数据

## 四、两个维度的客户价值语言

### 维度一：「我要一个能贴自己 Logo 的 AI 平台」

**客户需求翻译：**
> "我不想让员工用 ChatGPT——数据出去了、品牌是别人的、我什么也管不了。"
> "我想给我的客户搭建 AI 助手，但我不会写代码。"

**AI Pool 的回答：**
> **5 分钟让你的品牌拥有 AI 平台。** 替换 Logo、更换配色、选择你想展示的功能——剩下的 20MB 二进制文件全包了。不用招前端工程师，不用买服务器集群。

**可展示的定制点：**
- → 侧边栏品牌名（"XX 公司 AI 助手" vs "AI Space"）
- → 品牌色（TailwindCSS CSS 变量，深色/浅色双主题）
- → 功能菜单（要不要 PPT？要不要图片编辑？你决定）
- → 定价页面（你自己的套餐名称和价格）
- → 着陆页 SEO（搜索引擎展示你的品牌）

### 维度二：「我要一个稳定可靠的技术底座」

**客户需求翻译：**
> "我买的不只是一个 UI 皮肤——底层要稳、要强、要有深度。"

**AI Pool 的回答：**
> **聚合层 + 增强层：不止是路由转发。** 我们自研了文件 RAG 管线、图片编辑引擎、技能热加载系统、三级计费引擎——这些是其他聚合平台（OpenRouter、Poe）没有花功夫做的深度能力。

**技术底座清单（可直接用于销售沟通）：**
1. **多模型引擎**：统一流式接口 + 会话管理 + 中间件栈
2. **文件 RAG**：PDF→分块→Embedding→检索→引用，全自研管线
3. **图片工作台**：生成→编辑→移除→替换→提升，一个界面全搞定
4. **技能系统**：热加载、co_skills 组合、可编程 manifest
5. **积分计费**：Token 粒度、三级定价、完整生命周期
6. **安全体系**：JWT + bcrypt + IP 限流 + CORS + 访客/登录/会员三态
7. **单机部署**：20MB 二进制 + 零外部数据库 + 低资源消耗
